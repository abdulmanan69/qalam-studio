# Calligraphy fonts

Each font lives in its own folder together with its license. These files are **not** covered by
the project's MIT license; each keeps its own license, the SIL Open Font License 1.1.

| Folder                | Font                | Style    | Copyright / project                        | Source                                     |
| --------------------- | ------------------- | -------- | ------------------------------------------ | ------------------------------------------ |
| `noto-nastaliq-urdu/` | Noto Nastaliq Urdu  | Nastaliq | The Noto Project Authors                   | [google/fonts `ofl/notonastaliqurdu`][g1]  |
| `gulzar/`             | Gulzar              | Nastaliq | The Gulzar Project Authors                 | [google/fonts `ofl/gulzar`][g2]            |
| `amiri/`              | Amiri               | Naskh    | The Amiri Project Authors                  | [google/fonts `ofl/amiri`][g3]             |
| `amiri-quran/`        | Amiri Quran         | Display  | The Amiri Quran Project Authors            | [google/fonts `ofl/amiriquran`][g4]        |
| `scheherazade-new/`   | Scheherazade New    | Naskh    | SIL Global                                 | [google/fonts `ofl/scheherazadenew`][g5]   |
| `noto-naskh-arabic/`  | Noto Naskh Arabic   | Naskh    | The Noto Project Authors                   | [google/fonts `ofl/notonaskharabic`][g6]   |
| `aref-ruqaa/`         | Aref Ruqaa          | Ruqaa    | The Aref Ruqaa Project Authors             | [google/fonts `ofl/arefruqaa`][g7]         |
| `reem-kufi/`          | Reem Kufi           | Kufi     | The Reem Kufi Project Authors              | [google/fonts `ofl/reemkufi`][g8]          |

The exact copyright notice of each font is in its `OFL.txt`. The font files are unmodified.
Variable fonts (`*-Variable.ttf`) are renamed from the upstream `Name[wght].ttf` files only so the
file names are URL-safe. Aref Ruqaa and Reem Kufi declare Reserved Font Names: a modified version
(for example a subset) would have to be published under a different name.

To add a font, see [docs/adding-fonts.md](../../docs/adding-fonts.md).
