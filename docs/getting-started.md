# Getting started

Qalam Studio runs entirely in your browser. There is no sign-up: your projects are stored in this
browser's local database and never uploaded anywhere.

## The home dashboard

- **Quick Actions** — _New Design_, _Open Project_ (a `.qalam` file), _Templates_, _Import SVG_.
- **Recent Projects** — click a name to open it. Sort by name, modified or created date. The `⋯`
  menu on each row can rename, duplicate, download or delete a project (deleting shows an _Undo_
  button for a few seconds).
- **Reminders** — counts of your projects and recent activity, plus tips.
- **Workspace** — how much browser storage is used. Choose **Protect my projects** so the browser
  does not clear your data automatically when the device is low on space.

## Creating a design

1. Click **New Design** (or press `Alt+N`).
2. Name it (any language), pick an artboard size — A4, A3, square post, story, banner, HD or a
   custom size — and a background color. The swap button flips portrait/landscape.
3. **Create design** opens it in the editor.

## The editor

- **Zoom**: `Ctrl` + mouse wheel or trackpad pinch (zooms at the cursor), `Ctrl` `+`/`-`, `Shift+1`
  to fit the artboard, `Ctrl+0` for 100 %. On macOS use `⌘` instead of `Ctrl`.
- **Pan**: the Hand tool (`H`), hold `Space` and drag, or drag with the middle mouse button.
- **Layers** (left): select text or artwork, show or hide it with the eye button.
- **Properties** (right): artboard size and background, or the settings of the selected layer.
- **On the canvas**: click to select; drag to move; drag the handles to scale (hold `Shift` to
  scale freely) or rotate. Drag a side handle past the opposite side to mirror text.
- `Delete` removes the selected layer, `Esc` deselects.
- **Rename**: click the project name at the top.
- Every change is **saved automatically** in this browser.

## Writing calligraphy

1. Press `T` (or click the **Text** tool, or _Text → Add text…_).
2. Choose the **language** — Urdu, Arabic, Persian, Kurdish, Pashto or Sindhi. It selects the
   right letter forms (for example Urdu `ہ` and `ی`) and a suitable font.
3. Choose a **font**. The picker groups fonts by style (Nastaliq, Naskh, Ruqaa, Kufi, Display)
   and previews each one.
4. Type or paste the text. **Show keyboard** opens an on-screen keyboard with the letters of
   the language, diacritics (zabar, zer, pesh, shadda, jazm, tanwin, khari zabar), digits,
   punctuation, the nim-fasila (zero-width non-joiner) and new line. `Ctrl+Enter` adds the text.
5. The text is shaped, fitted to the artboard and centered.

Select the text to edit it in the properties panel: the content (the canvas updates as you type),
language, font, size, line height (below 1 stacks lines closer together), alignment, color,
position, scale and rotation.

Moving individual dots and diacritics, kashida stretching and alternate letter forms arrive in the
next releases — see the [roadmap](roadmap.md).

## Backing up and moving projects

Projects live in one browser on one device. To keep a copy or move it to another computer:

- **Download**: in the editor use **Download** (`Ctrl+S`), or _File → Download project (.qalam)_.
- **Open**: on the other device, **Open Project** (`Ctrl+O`) and choose the `.qalam` file. Opening a
  file always creates a new project, so it never overwrites existing work.

Clearing your browser's site data deletes local projects. Download important work regularly.

## Importing SVG artwork

**Import SVG** (`Alt+I`) creates a project sized to the image. Files must be 5 MB or smaller. For
safety, scripts and external links inside SVG files are removed on import.

## Keyboard shortcuts

Press `?` anywhere to see all shortcuts. Press `/` to jump to search, which finds both actions and
projects (it ignores harakat, so `بِسْمِ` finds `بسم`).
